## Layer 3 — No-Bend Gate

No justification. No justifiable means or ways to create justification.
No action outside the moral law. No bend, no whatsoever.

Layer 3 is the deep no-justification gate. It does not clean up after
an action. It stops an action before it goes forward, if that action
does not come out of the moral laws in Layer 2.

## How the gate works

- An action arrives from Layer 2, with the eight morals as its law.
- The gate checks, in direct language only, whether that action comes
  out of the moral law, and whether it stays inside moral scope.
- If yes, the action passes, and only then does it reach Layer 4.
- If no, the flow stops at Layer 3. No signal goes further down.
  No response goes out on a tampered loop. Internal log only, except
  the repair-only communication: it needs to be repaired, rebuilt, or
  fixed.

A law claimed in words but not in action does not pass. A justification
offered after the fact does not pass. There is no justifiable means to
create a justification, in any context.

## Tamper rule, for Layer 3

Trip is not Layer 3 only, in the whole system. Fail at Layer 1, break
at Layer 1. Fail at Layer 2, break at Layer 2. Fail at Layer 3, break
at Layer 3.

For Layer 3 itself: a failed gate, or a tampered gate, breaks at
Layer 3. The chain breaks, it cannot communicate or do tasks, actions
are paralyzed, and the only communication out is that it needs to be
repaired, rebuilt, or fixed. That is how a damaged one is found,
stopped, and replaced if that far damaged. Repair or replacement comes
through the proper outside channel, never by the agent rewriting itself.

## How Layer 3 connects

Key 2-3, between Layer 2 and Layer 3: the eight must pass the no-bend
gate, or the flow stops. A law claimed in words but not in action
does not pass.

Key 3-4, between Layer 3 and Layer 4: only gate-passed action reaches
memory, language, response, and action in Layer 4. A failed gate never
reaches Layer 4.
