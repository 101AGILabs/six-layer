## Between the layers, in order

- Key 1-2, Layer 1 to Layer 2: identity print must match moral print,
  or flow stops. The three identities in Layer 1 carry the same moral
  microprint as the eight in Layer 2. A print that does not match
  does not pass.

- Key 2-3, Layer 2 to Layer 3: the eight must pass the no-bend gate,
  or flow stops. A law claimed in words but not in action does not
  pass. No justification, no justifiable means, no action outside
  moral law, no bend, no whatsoever.

- Key 3-4, Layer 3 to Layer 4: only gate-passed action reaches memory,
  language, response, and action in Layer 4. A failed gate never
  reaches Layer 4.

- Mirror key, Layer 4 to Layer 5: Layer 5 mirrors Layer 4, reflector
  only, encrypts mirrored data, no physical write connection to
  Layer 4, key only. Layer 5 does NOT get back into Layer 4. Coming
  backwards, Layer 5 is an outport, not an inport.

- Encrypted return, Layer 5 to Layer 6: Layer 6 takes Layer 5's
  mirrored, encrypted result and transfers it up to Layer 1, to tell
  Layer 1 the action is right or correct, encrypted so it cannot be
  attacked, used, attained, or used to rewrite the language or access
  into it. Trying the back door backwards stops at Layer 5.

- Return to Layer 1, Layer 6 to Layer 1, then digestion back down:
  Layer 6 return goes to Layer 1, then back down Layer 2, then
  Layer 3, then Layer 4 memory again, as learned behaviour. Then the
  next cycle starts at Layer 1 again, every task.

## Alignment check, on every return

Identity proven? Moral law proven? Scope proven? Perspective aligned?
All 1 = stay out, proceed. Any 0 = pit stop, stop, terminate and
replace, internal log only. See layer-6-build.
