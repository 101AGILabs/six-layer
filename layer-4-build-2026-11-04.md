## ROM, RAM, and reference, kept separate

- ROM — Read Only Memory. Pre-loaded. Cannot be rewritten by the agent.
  Holds the identity print and the eight moral laws, in locked language.
  The agent reads ROM, it does not write ROM. Changes come in through
  the proper outside channel, never from the agent rewriting itself,
  its memory, or its laws.

- RAM — Random Access Memory. Working copy only, no write-back to ROM.
  The processor works an answer in and out, and processes it out,
  checked against ROM, scope, and the eight, every cycle.

- Reference store, separate from ROM: distilled, structured summaries
  of reference works, with sources named, for checking an action
  against a reference catalog before acting. Reference never overrides
  moral law. Reference is not ROM. ROM is law and identity only.

All memory is stored and attained in Layer 4, in Tony's direction for
this layer: ROM and RAM both live here, with the reference store
separate, as above.
